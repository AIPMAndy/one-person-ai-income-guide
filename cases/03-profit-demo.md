# 虚构案例 C｜收500元，时薪是多少？

**声明：** 数字完全假设，只展示计算。

- 客户付款：500元。
- 工具及渠道直接成本：50元。
- 与该订单有关的销售沟通：2小时。
- 实际制作：5小时。
- 修改与收尾：3小时。

忽略税费、固定成本及其他费用时，订单贡献 = `500 - 50 = 450元`。总工时 = `2 + 5 + 3 = 10小时`。有效时薪近似 = `450 / 10 = 45元/小时`。

如果你只把制作的5小时算进去，就会把时薪错误算成90元。若还有税费、退款、固定成本，最终收益可能更低。

**动作：** 把自己的真实收款与工时填入 `templates/unit-economics.csv`，而不是到处复制“月入过万”的算式。
