# Prompt 13｜公开 JD 拆解（不上传真实简历）

复制以下 Prompt 至你有权使用的模型，并补充 **公开 JD 或虚构岗位**：

```text
任务：依据下面已经公开的岗位 JD，构建一个可人工核对的岗位要求表。
输入：【把你有权处理的公开岗位要求粘在这里】
输出：每条岗位原文、能力归类、可展示的证据类型、候选人需要自己补充的事实、AI推断标记。
规则：不要改写岗位原文；不编造公司、薪水、录用门槛，不推断求职者性格或身份；任何输入未包含的信息必须写「未知」。
先复述你识别的来源、发布日期和可能过期点，再输出表格；最后列需要人工检查的 5 项。
```

验收：每行要求都能回指输入；没有候选人真实个人资料；问号字段全部由本人回答。若需要真实简历处理，先执行 [数据处理闸门](../templates/data-handling-checklist.md)。
