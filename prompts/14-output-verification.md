# Prompt 14｜AI 工作结果逆向复核（第二模型可选）

```text
你是交付审校员，不是营销文案写手。请审核下面我有权处理的非敏感内容，不自行上网编证据。
[原始已核实资料]：...
[AI草稿]：...
请输出六栏：主张、所需证据、现有出处、是否严格支持、风险等级、人工修改建议。
任何无法由输入直接支持的主张标「待核/删除」，任何数字、收入结果、法规、效果承诺都要逐项检查。不得为缺失的信息填想象数字。
最后列出会阻断客户交付的错误，以及修复后怎样再次测试。
```

执行时：人工打开原始来源，独立核查。**让另一个模型审核不构成事实证明**。证据缺口处理见 [事实核对表](../templates/qa-fact-register.md)。
