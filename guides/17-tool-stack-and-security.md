# 17｜软件与安全：最低成本组合、客户信息、Agent 权限

## 起步软件清单：功能优先于品牌

| 功能 | 零成本可做的替代 | 升级条件 |
|---|---|---|
| AI 文本辅助 | 使用合法可用、有免费额度或现有授权的模型 | 每单节省工时可实测覆盖费用 |
| 文档/表格 | 本机 Markdown、CSV、LibreOffice 或已有办公套件 | 必须多人协作或复杂公式时 |
| 设计/视频 | 已装软件或经许可的免费软件 | 客户要求商业字体/素材许可时 |
| 文件托管 | 本地受控目录 + 加密备份 | 远程协作需要细粒度权限时 |
| 自动化 | 先用规则文档与人工操作 | 高频、低风险、可回滚时 |
| 客户管理 | `leads.csv` | 线索量已超手动追踪能力时 |

本文不提供任何跨区绕限制、购买他人账号或低价黑产 API 的做法。模型订阅费用、商用范围、数据使用和区域支持均会变动，**不能用一个平台的默认隐私设置推断别的平台**。

## 客户数据“四步闸门”

1. **分类**：公开资料、自有作品、获得授权的非敏感资料、个人信息/敏感个人信息、商业秘密、账号凭证。
2. **判断授权与必要性**：客户说“可以用 AI”不自动等于所有数据都能传第三方；还需看合法处理依据、个人信息权益和供应商政策。
3. **最小化**：优先在本地用虚构示例、汇总数据或真实脱敏资料（不能可逆还原）；有不能去除的个人隐私，**不得默认进入普通第三方 AI**。
4. **权限与处置**：约定可用平台、保存期限、访问人、数据回收/删除方式；发生泄露及时采取止损和合规处置。

**注意**：关闭模型训练用途的开关不等于零留存、零风险，也不等于自动具备处理客户资料的法定资格。以供应商最新条款/所在计划/具体账号设置为准。比如 [ChatGPT 数据控制官方说明](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt) 与 [OpenAI 数据使用说明](https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance)。

## Agent 最小权限表

| 操作 | 默认权限 | 为什么 |
|---|---|---|
| 读取本地匿名演示 CSV | 可在隔离测试目录 | 可重复、低风险 |
| 自动编辑公开示例文档 | 可保留版本与 Diff | 可回滚 |
| 访问客户私有目录 | 默认禁止，逐项授权 | 防超范围访问 |
| 发送营销消息/发布内容 | 必须人工批准 | 账号安全、平台规则 |
| 转账/退款/发票/购买订阅 | 必须人工批准 | 财产风险 |
| 删除客户文件/改权限 | 必须人工批准且备份 | 不可逆风险 |
| 上传客户信息到模型 | 默认为禁止；合法审核后放行最小集 | 第三方处理及跨境传输风险 |

交付给客户之前用 [权限与数据处理单](../templates/data-handling-checklist.md) 和 [自动化测试表](../templates/automation-tests.csv)。
