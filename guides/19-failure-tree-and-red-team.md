# 19｜完整失败树：二十种看完仍赚不到钱的情况

本章是逐项故障处理手册。按**先定位故障阶段、再找证据、最后做最小修复**执行；不根据“感觉挺好”改变所有变量。

| 症状 | 优先根因 | 当天可验证动作 | 禁止的错误补救 |
|---|---|---|---|
| 不知道卖什么 | 客群太宽 | 写出一个具体人群与真实动作 | 同时注册20个工具 |
| AI 生成效果差 | 缺少可信原料和验收 | 用真实授权或虚构标准输入重跑 | 直接把输出发客户 |
| 访谈没人聊 | 接触渠道不合适 | 请求转介绍或参与行业公开交流 | 买私人手机号名单 |
| 访谈都夸好 | 没问过去真实采购 | 询问上次付费/实际支出 | 记为订单 |
| 有痛点没预算 | 付款人没找到 | 查审批与预算来源 | 用“错过会后悔”逼单 |
| 发消息没回复 | 冷启动无信任 | 提供一页真实样稿 | 批量追问/轰炸 |
| 有回复没下一步 | 动作过大 | 约15分钟判断需求 | 一上来卖整套 SaaS |
| 三次报价被拒 | 范围/信任/时机错误 | 比较客户现有替代方案 | 每次都打五折 |
| 客户只想免费 | 未设沟通范围 | 给免费知识与有限演示 | 恐吓式关单 |
| 订金迟迟不到 | 采购未批准 | 等待书面与实际资金确认 | 按承诺资金扩支 |
| 收款后信息不全 | 输入清单缺漏 | 发材料检查表，确认交期变化 | 猜数据编出来 |
| 输出有幻觉 | 证据链断裂 | 一条条回原文审查 | 把模型说法当来源 |
| 音乐/图像侵权 | 权属未查 | 换自有/许可素材 | “网上公开就能商用” |
| 客户要求造假 | 不可交付内容 | 书面拒绝虚构履历/评价 | 用 AI 生成假证明 |
| 需求无限增加 | SOW 缺变更流程 | 发变更报价与新工期 | 无限免费加内容 |
| Agent 改坏数据 | 生产直连且无回滚 | 停止写权限，恢复备份 | 让 AI 自动继续重试 |
| 私有资料外泄 | 上传第三方前没审查 | 停用流转、保存必要记录并应对 | 删除日志掩盖问题 |
| 客户拖尾款 | 验收节点不清 | 对照书面验收条款协商 | 公开威胁曝光资料 |
| 已收很多钱但没利润 | 漏记工时和税费 | 重建订单成本账 | 继续降价扩张 |
| 开源没人点赞 | 首页缺可执行成果 | 测首屏/任务/示例打开体验 | 购买 Stars/刷量 |

## 五级停止规则

1. **信息安全风险**：停止上传、转账、发布和自动化写入，人工复核；必要时按约定及法律处理通知。
2. **涉嫌虚假承诺**：立即移除未证实的收益/效果叙述与造假案例。
3. **交付能力不足**：停止接高风险订单，先做可证明的演示与技能训练。
4. **流动性不足**：保留现实就业/兼职路线，不借钱买昂贵工具或投广告。
5. **连续实验无付款**：保留访谈与拒绝数据，调整客群/价值/渠道中的一个变量，避免盲目坚持同一假设。

把每一次失败复盘写入 [实验日志](../templates/experiment-log.csv)。失败不是“被证明能成功”，可能意味着应及时停止方向。
