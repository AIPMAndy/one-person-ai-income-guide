# 21｜30天每天做什么：执行版日历

本日历适合每天有 60～120 分钟的人；时间有限则按顺序做，不以“赶进度”为理由跳过客户授权或质量校验。每一天都有最终产物。**30 天内是否能收款取决于需求、交付和客户决策，不做承诺。**

| 日 | 任务 | 产物 |
|---|---|---|
| 01 | 算现金、时间与已有技能 | 现金表、能力表 |
| 02 | 选一个人群和购买事件 | 客群卡 |
| 03 | 定义一个可售结果和排除项 | 一页服务说明 |
| 04 | 通过公开渠道研究现有替代方案 | 竞品替代记录 |
| 05 | 制作匿名/虚构演示材料 | 一页样稿 |
| 06 | 找第一个有意愿接受访谈的人 | 1份访谈笔记 |
| 07 | 汇总客户问题，继续或停止 | 7天复盘 |
| 08 | 整理 10 个合适且合法触达的对象 | 线索表 |
| 09 | 完成 2 次针对性需求访谈 | 访谈摘要 |
| 10 | 改样稿：用客户原话重写标题 | V2 样稿 |
| 11 | 做事实/版权/安全验收 | 样稿 QA 表 |
| 12 | 再做 2 次访谈 | 4 条行为证据 |
| 13 | 整理 3 个客户常见异议 | FAQ 初稿 |
| 14 | 选定唯一试售的服务包 | 价格范围卡 |
| 15 | 给明确有意向的人提供一次书面报价 | 报价记录 |
| 16 | 澄清输入、交付与验收 | SOW 草案 |
| 17 | 比较客户原有方案的成本与结果 | 替代方案表 |
| 18 | 解决一个真实拒绝理由 | 修改版报价 |
| 19 | 再做一次报价或复盘无人购买原因 | 报价日志 |
| 20 | 算一单现金和全部工时 | 利润预估 |
| 21 | 阶段闸门：有实付订单？ | 继续/转向决策 |
| 22 | 若成交：收集最少材料；未成交：再访谈 | 授权清单/访谈 |
| 23 | 若成交：做第一轮草稿；否则改客群 | 可审查草稿 |
| 24 | 做事实、格式和版权检查 | QA 记录 |
| 25 | 与客户核对范围与差异 | 变更记录 |
| 26 | 完成交付或新的演示样例 | 可打开文件 |
| 27 | 获取书面验收或真实试用反馈 | 验收/反馈 |
| 28 | 对账、核实真实现金流 | 收入成本表 |
| 29 | 在允许时请求独立反馈或案例授权 | 可公开边界 |
| 30 | 写证据复盘，制定下一周期计划 | 复盘报告 |

**每天的最低动作**：打开上一天的实际交付物，把唯一瓶颈写一句，然后完成一项可以检查的动作。单纯学习视频 2 小时、安装插件 5 个，不自动视为创业进度。

**第 7、14、21、30 天的判断**：没有真实需求就调整市场；有人买但做不完就提高交付能力/缩小范围；做得出但亏损就调范围/成本/价格；没收入又现金紧张就优先现实就业。
