# 销售漏斗数据字典｜防止虚假转化率

| 阶段 | 可计入条件 | 不可计入 |
|---|---|---|
| 线索 | 合法来源、有合理相关性的独立潜在客户 | 抓取的陌生人私人电话 |
| 已触达 | 在允许的渠道发出明确一次消息 | 机器人潜在发送列表 |
| 已回复 | 真人主动回复并涉及本次服务 | 无关表情、机器人回复 |
| 有效需求 | 有过去行为、交期、需求及可判断的预算路径 | 单纯“厉害”“支持” |
| 正式报价 | 具体范围+价格+交付+条件发送给买方 | 朋友圈挂价格 |
| 已确认订单 | 双方按约定方式确认订单/合同 | 对方说“有空考虑” |
| 已实收 | 银行/平台账单可确认已到账且非测试款 | 转账截图、待支付订单 |
| 已验收 | 交付符合约定且留有核验记录 | 单纯发送文件 |
| 复购 | 独立新周期已确认购买/收款 | 询问下一次价格 |

不要拿“点击数”当线索、“私信数”当客户、“咨询收口”当实收；税费与退款另外核对。
