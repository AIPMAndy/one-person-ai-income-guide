# 交付前人工质检清单

- [ ] 已确认客户实际要解决的问题和交付范围
- [ ] 对所有非公开客户数据有适当处理依据、授权及脱敏措施
- [ ] 输入数据中不存在无权使用的身份证、密码、API key、商业秘密
- [ ] 事实、数字、出处与时间逐项核实，没有凭空补数字
- [ ] AI 的结论能够被人工解释，未知信息明确标注未知
- [ ] 文件均能打开，编码、可编辑性、格式、排版正确
- [ ] 所有图片、音乐、字体及第三方素材有合适许可
- [ ] 对外 AI 生成内容已做所需声明/标识
- [ ] 涉及发送、支付、删除、修改权限等操作由人确认
- [ ] 异常流程、撤销/回滚、费用上限、暂停方式可用
- [ ] 与报价约定的验收条件逐条比对
- [ ] 客户确认验收；保存必要凭证但不公开隐私
- [ ] 记录本单实收、支出、总工时和未解决问题
