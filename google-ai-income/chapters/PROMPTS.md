# Google AI 赚钱 · 16 套可复制任务 Prompt

将花括号替换为你有权使用的信息；涉及真实客户数据前先取得授权。

## 01｜需求访谈 · 客户访谈问题

```text
你是业务发现顾问。行业：{行业}；买家角色：{角色}。生成 8 个开放式访谈问题：最近一次实际发生的任务、频率、耗时、现有替代、真实成本、审批者、预算路径和不可接受风险。禁止引导式提问、禁止臆测预算。输出表格：问题/要核实的事实/什么回答算有购买证据。
```

## 02｜研究 · 竞品证据矩阵

```text
基于以下我已授权/公开的来源文本：{材料}。输出 3 家竞品对照表：产品/目标用户/官方价格原文/功能/来源链接/日期/不确定项。若某字段无可靠来源则写“未验证”，禁止编造。最后提出待人工核对的 5 个问题。
```

## 03｜研究 · 事实与幻觉红队

```text
审查这份报告：{报告}。逐条列出事实性主张，分 A 有官方来源、B 第三方采访、C 推断、D 无来源。指出过时数据、无依据因果关系、真实引用可能错误之处。禁止自己补造来源链接。
```

## 04｜商家 · 本地商家真实 FAQ

```text
门店授权信息：{信息}。生成 10 个真实可回答的客户问题，按咨询频率假设排序并标明“假设”。每条包含：适用人群/回答草稿/需店长确认的具体事实/禁用绝对承诺。不可编造销量、评价、证照、维修案例。
```

## 05｜商家 · 7 条脚本分镜

```text
根据已核准的产品事实：{事实}，制作 7 条 20–40 秒短视频脚本，分别采用误区、操作、问题、对比、客户须知、幕后、FAQ 角度。每条写标题、前 3 秒、镜头、台词、核验点、CTA。不能使用虚构客户证言。
```

## 06｜视频 · Flow 镜头提示词

```text
为一个已授权的品牌做 15 秒视频。商品：{商品}，场景：{场景}。输出 5 个镜头的英文生成提示词及中文意图，每个包含主体、镜头运动、光线、动作、时长。避免知名人物面部和受保护角色；每镜头增加人工检查项。
```

## 07｜开发 · AI Studio Build PRD

```text
我要用 Google AI Studio Build 做一个可演示网页。目标用户：{用户}；唯一核心任务：{任务}；输入字段：{输入}；可核验输出：{输出}。先生成用户故事、边界、异常清单、10 条测试用例；后给出可直接粘贴的应用生成 Prompt。API Key 只允许服务端 secrets；不得存在前端。
```

## 08｜开发 · 安全与成本检查

```text
审核这份 Gemini API 应用方案：{方案}。检查：服务端 Key、鉴权、配额与预算阈值、请求大小、日志脱敏、数据保留、重放/滥用、失败降级、可恢复性。以严重级别排序，给修复步骤及验收方式。
```

## 09｜自动化 · 人工审批工作流

```text
业务场景：{场景}。输入样本全为虚构数据：{样本}。设计 4–7 步工作流：字段验证→模型草稿→事实/权限检查→人工批准→输出存档。每步写输入/输出/失败分支/停止条件。不要自动向第三方发送消息。
```

## 10｜培训 · 企业培训课纲

```text
岗位：{岗位}；员工熟练度：{水平}；真实可授权的任务：{任务}。输出 2 小时课纲、10 道练习、样例答案、人工核验 rubric（正确性/可追溯性/安全性/节省时间）。不承诺未经测量的效率提升。
```

## 11｜跨境 · 多语言落地页本地化

```text
目标市场：{市场}；语言：{语言}；已批准卖点：{卖点}。写出落地页标题、三项利益点、FAQ 和 CTA，再提供术语表和需要本地人复核的法规/文化问题。禁止新增功效声明、销量、认证。
```

## 12｜内容 · 原创 YouTube 结构

```text
我的亲身经历和独立结论：{经历}。可靠来源链接：{来源}。产出 6 分钟 YouTube 讲解结构：反常识开头→证据→亲身例子→反方观点→操作建议→结语；标注哪些画面用 AI 需要披露。拒绝拼接洗稿。
```

## 13｜销售 · 一页服务报价单

```text
客户问题：{问题}；交付物：{交付}；可用工时：{工时}；成本：{成本}。生成一页报价草稿，必须包含范围、格式、交付时间、2 条可测验收条件、客户素材责任、付款条款、修改次数和不包含事项。金额先空着由我填。
```

## 14｜销售 · 非骚扰式访谈邀请

```text
与收件人的真实关联：{关联}；希望反馈的演示样稿：{样稿}。生成 100 字内 1:1 访谈邀请：自我介绍、具体关联、5–10 分钟请求、可拒绝的结束语。不伪造熟人关系，不群发。
```

## 15｜交付 · 交付验收清单

```text
请基于已书面确认的交付范围：{范围}，制作验收清单，列：交付件、文件格式、来源/事实核验、隐私/商标/版权检查、修改次数、签收负责人、证据位置。不要擅自增加合同外承诺。
```

## 16｜交付 · 失败复盘与止损

```text
本次实验记录：{访谈次数/样稿反馈/真实报价/已到账/工时/支出}。只做证据与假设的区分。列出 3 个最可能瓶颈、下一轮只改动 1 项变量的试验方案、明确的停止条件；不能推断“流量增长必然带来收入”。
```
